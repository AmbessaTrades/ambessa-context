# What is still open

Nothing in this file is decided. It exists so an agent asks the right question instead of
assuming an answer.

1. **The first deal pair.** Which named company, and which named government body, is the first
   Second Opinion or Authority File written for. Without two names, the work is research.
2. **Who signs first — company or agency.** The company sale is faster and colder; the agency
   sale is slower and recurring. The opening move is not settled.
3. **Whether the first paying work is the dossier, the border desk, or the aftercare product.**
   Each implies a different first month.
4. **How the confidentiality wall works** if the same firm sells both directions. Two brands,
   or one rule.
5. **What the published proof is.** The one artefact a stranger can read that makes the claim
   credible without a prior relationship.
6. **What content sells** — the problem, the product, or the person. The current assumption is
   the problem plus the person, but it has not been tested against a real audience yet.
7. **Where the first five clients come from** — reply-game conversations, warm introductions,
   or an outbound list built from the procurement records.

Ask about these. Do not resolve them on your own.
