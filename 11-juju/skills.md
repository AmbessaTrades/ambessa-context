# The Juju skills

As of 02:43 EAT, Thu 26 Nov 2026. One folder per skill in the private repo (`crates/juju-skills/packs`), each a page for agents plus a JSON the app embeds. Agents use them while building; the app must act on them while making a film. Bodies stay private; this is the map.
